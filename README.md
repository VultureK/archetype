# Archetype
An online MIDI-sequencer made purely for fun.

One day I wanted to code a MIDI sequencer for a browser by myself. I wasn't happy with the MIDI sequencers we had online... so I wanted to create the ultimate one. Presenting to you, Archetype. Based off of early versions Cubase, FL Studio, and Ableton.
This software is supposed to heavily be based off of older DAWs you'd see in the late 1990s and early 2000s. Did I fail at capturing the essence? Most absolutely likely.

Note: Archetype is VERY, very new! Things will be broken. Things you might be wanting aren't added yet. If you want to help this project grow, then go ahead! Snatch this project and do cool stuff with it.

## Features
1. A mix of a pattern-based and linear timeline: every track is it's own instrument and has its own group of patterns that are locked to it.

2. Easy importing and exporting of MIDI files: easily import MIDI files and edit them, or make up your own MIDI track and export it.

3. Instruments: A main instrument in this is soundfonts! soundfonts included are: FluidR3_GM and MusyngKite. We also have an oscillator instrument with basic shapes and an Operator instrument, inspired by Ableton.

4. Themes: Graphite, Basic, Vindows Vista, and FL Studio. My personal favorite is Basic :)

5. Effects: EQ, Reverb, Overdrive, Delay, Filter, Tremolo, and Compressor.
